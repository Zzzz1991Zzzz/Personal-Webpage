# Yang Zhang Personal Website

This is a static personal website designed for GitHub Pages deployment.

## Files

- `index.html`: main page
- `styles.css`: site styling
- `script.js`: small interaction effects
- `Resume_Yang_Zhang_UCSD_MSCE.pdf`: downloadable resume

## Deploy to GitHub Pages

1. Create a new GitHub repository.
2. Upload all files in this folder to the repository root.
3. Push the repository to GitHub.
4. In GitHub, open `Settings > Pages`.
5. Under `Build and deployment`, choose:
   - `Source`: `Deploy from a branch`
   - `Branch`: `main`
   - `Folder`: `/ (root)`
6. Save and wait about 1 to 3 minutes.
7. Your site will be available at:
   - `https://<your-github-username>.github.io/<repo-name>/`

## Optional

- If you want the site to live at `https://<your-github-username>.github.io/`, create a repository named exactly `<your-github-username>.github.io`.
- You can later replace the contact section with GitHub, LinkedIn, or Google Scholar links.
